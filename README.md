# Lyra AI Chat

Crie uma aplicação web moderna de chat estilo ChatGPT/Gemini chamada "IF", com a assistente "Lyra AI".

Design e identidade:
- Tema escuro moderno (#0C0A10) com detalhes, bordas sutis e destaques no roxo elétrico (#9333EA) da IF Productions.
- No topo da área de chat, exiba a marca "IF AI" e o slogan "O Mundo Precisa de ti".
- Barra lateral retrátil no lado esquerdo com navegação, novo chat e histórico de conversas.
- Caixa de digitação centralizada e flutuante na parte inferior da tela.
- Abaixo da caixa de texto, aviso discreto: "A Lyra é uma IA e pode cometer erros."
- Modal/aba de Configurações (ícone de engrenagem) onde o usuário pode inserir sua chave de API do OpenRouter e escolher o modelo para alimentar as respostas da Lyra AI.
- Suporte a streaming de mensagens ou respostas simuladas/reais com OpenRouter, renderização em Markdown com suporte a código e formatação rica.
